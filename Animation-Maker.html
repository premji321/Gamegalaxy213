Studio Help

Rotate camera: Drag the mouse or finger over the 3D viewport.

Zoom: Use the mouse wheel or the + / − buttons.

Move character: Select Walk or Run and press Play Animation.

Change character: Update the character settings and press Create / Update.

Change scene: Choose an environment and press Build Environment.

Video recording: Press Record Video, allow the recording to finish, and download the resulting WebM file.

Project saving: Save or export a JSON project file. This is not a rendered video.

This studio uses procedural 3D geometry. It does not contain a full skeletal animation rig or an AI text-to-video model.
